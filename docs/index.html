Put your keyboard shortcuts on your mouse.

Clicklet maps mouse buttons 4 and 5 to any shortcut you like: Ctrl+Enter, Ctrl+C, Win+Shift+S. One native app, an optional config file, no ads, no tracking. Free and open source.

Run it. Nothing to set up.

With no config file, button 5 sends Ctrl+Enter. Want something else? Put Clicklet.ini next to the executable.

Clicklet.ini
[Mapping]
Button4=ctrl+c
Button5=ctrl+v
  • That’s the whole config. Up to two mappings, one shortcut per button.
  • Leave a button out. It keeps its normal behavior.
  • Edits apply on restart. Invalid settings are reported at startup.

Frequently Asked Questions

Which buttons can I map?

Mouse buttons 4 and 5, the two side buttons. One shortcut each, so two mappings at most. Left, right and middle click are never touched.

Does my Back button still work?

A mapped button sends its shortcut instead of its normal click. Buttons 4 and 5 are Back and Forward by Windows convention, so once you map one, it stops going back or forward. A button you leave unmapped is untouched.

What can a button send?

One key, optionally combined with Ctrl, Alt, Shift or Win. Plain keys stay down for the physical duration of the mouse press. Duplicate presses are ignored; two buttons mapped to the same plain key share the hold until both are released. Modifier shortcuts remain one-shot combinations sent on press. Clicklet generates no repeat events. Windows can refuse injection or release, and physical keyboard state can interfere with mapped holds. Supported keys are letters, digits, F1–F24, Enter, Tab, Esc, Space, Backspace, Delete, Insert, Home, End, Page Up, Page Down and the arrow keys. No macros, key sequences, media or volume keys, and no per-app profiles.

Will it work with my mouse?

If Windows reports your side buttons as buttons 4 and 5, yes. Mouse-vendor software can intercept them before Clicklet sees them.

Does it work on Windows 10?

This fork targets Windows 11, x64. See the fork documentation for validation details; Windows 10 is not a supported target.

Does it work in apps running as administrator?

No. Clicklet doesn’t ask for admin rights, and Windows won’t let it send input to windows that have them.

How is this different from AutoHotkey?

Clicklet isn’t a scripting system. There’s no scripting language and no script to maintain. At most two lines in a text file, or no file at all.

How is this different from PowerToys?

PowerToys Keyboard Manager remaps keyboard keys and shortcuts. Clicklet does one thing: mouse buttons 4 and 5 to keyboard shortcuts.

Do I need my mouse maker’s software?

No. Clicklet works without a mouse-vendor configuration suite. It’s one small portable app.

Where are my settings?

In Clicklet.ini next to the executable, if you made one. Clicklet only reads it, and picks up edits when you restart it. If the first line isn’t recognized, save the file without a BOM.

Can I turn it off for a moment?

Uncheck Enabled in the tray menu. The generic tray icon reverses its dark and light fill when disabled. Clicklet starts enabled every time it runs.

Does it start with Windows?

Not by itself. Put a shortcut to Clicklet.exe in shell:startup.

Why does Windows warn me on first run?

The executable isn’t code-signed, so SmartScreen flags it as unrecognised.

Does it send or write anything?

No network connections, no telemetry, no logging. Clicklet never writes files or registry entries. It only reads the optional Clicklet.ini. The source is one C++ file if you want to check.

How do I uninstall it?

Exit it from the tray menu and delete the files. Nothing was installed and nothing was written outside the folder.
